! Description: Supplementary $removeparam rules for gaps the upstream lists
!   (ClearURLs / Brave / AdGuard URL Tracking) don't cover. Param-strip only, in
!   ABP $removeparam syntax so they're upstreamable to AdGuard/uBO and run in
!   Unfurl's ABP pass alongside them. Redirect-unwrap rules live in
!   unfurl-debounce.json — ABP $removeparam can't express extract-and-redirect.

! Homepage: https://github.com/johnnywell/unfurl-rules
!

! --- Klaviyo subscriber ID (all hosts, 2026-09-28) ---
! A custom UTM that Klaviyo senders map to the recipient's profile ID (a
! 26-char ULID), so it identifies the person, not the campaign. ClearURLs's
! utm_* regex already strips it at copy-time, but Safari's click-time DNR rules
! take literal names only, and AdGuard/Brave list Klaviyo's _kx but not this.
$removeparam=utm_klaviyo_id
